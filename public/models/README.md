# Local vision and approximate geometry assets

`face_landmarker.task` and `hand_landmarker.task` are MediaPipe Task models downloaded from Google MediaPipe's public model storage for browser-local inference. The respective task files are versioned source artifacts and are loaded only when face or hand fitting is requested.

The GLBs are generated by `scripts/generate_jewelry_models.py`. They represent fitting geometry only; the product photographs remain the visual source of truth.
